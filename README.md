EduTransform is an inclusive web-based learning application designed for all students, including Children with Special Needs (CWSN), following the NCERT and CBSE curricula. Built on the principles of Universal Design for Learning (UDL), the platform incorporates tailored accessibility features such as a dedicated dyslexia-friendly typography stack and visible focus outlines for keyboard navigation. EduTransform enhances student engagement and long-term retention through an AI Socratic Tutor and spaced repetition strategies. Developed as a single-page React application, it provides an accessible, adaptive, and supportive digital environment to deliver quality, personalized education to every learner.
